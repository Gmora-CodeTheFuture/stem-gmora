Python Inheritance

Inheritance allows us to define a class that inherits all the methods and properties from another class.

27 Parent & Child

Parent and Child Classes

Parent class is the class being inherited from, also called base class. Child class is the class that inherits from another class, also called derived class.

parent.py
# Parent Class
  class Person:
      def __init__(self, fname, lname):
          self.firstname = fname
          self.lastname = lname

      def printname(self):
          print(self.firstname, self.lastname)

  x = Person("John", "Doe")
  x.printname()
27 Creating a Child Class

Creating a Child Class

To create a class that inherits the functionality from another class, send the parent class as a parameter when creating the child class.

child.py
class Person:
      def __init__(self, fname, lname):
          self.firstname = fname
          self.lastname = lname
      def printname(self):
          print(self.firstname, self.lastname)

  # Child Class inheriting from Person
  class Student(Person):
      pass # Use pass if you don't want to add any other properties or methods

  x = Student("Mike", "Olsen")
  x.printname()
27 Overriding __init__

Adding the __init__() Function

When you add the __init__() function in the child class, the child class will no longer inherit the parent's __init__() function. To keep it, you must call it explicitly.

init.py
class Person:
      def __init__(self, fname, lname):
          self.firstname = fname
          self.lastname = lname

  class Student(Person):
      def __init__(self, fname, lname, year):
          # Call the parent's init function
          Person.__init__(self, fname, lname)
          # Add a new property
          self.graduationyear = year

  x = Student("Mike", "Olsen", 2024)
  print(x.graduationyear)
27 The super() Function

Using the super() Function

Python also has a super() function that will make the child class inherit all the methods and properties from its parent, without needing to name the parent class explicitly.

super.py
class Person:
      def __init__(self, fname, lname):
          self.firstname = fname
          self.lastname = lname

  class Student(Person):
      def __init__(self, fname, lname, year):
          super().__init__(fname, lname)
          self.graduationyear = year

  x = Student("Mike", "Olsen", 2024)
  print(x.firstname, x.graduationyear)
27 Summary

Recap

✓Use class Child(Parent): to inherit.
✓Children inherit all methods and properties from parents.
✓Use super().__init__() to easily call the parent's constructor.
✓You can add new properties or override existing methods in the child class.
