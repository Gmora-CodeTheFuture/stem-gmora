User Input

How to ask the user to type information into your program.

34 input()

The input() Function

Python allows for user input. That means we are able to ask the user for input using the input() function.

input_basic.py
username = input("Enter your username: ")
  print("Welcome back,", username)

(When you run this in our web editor, a popup box will ask for your input!)

34 Data Types

Input is Always a String

No matter what the user types, the input() function ALWAYS returns a string. If you want a number, you must cast it.

input_types.py
age = input("Enter your age: ")
  print(type(age))  # This will be !

  # This will cause an error because age is a string:
  # print(age + 5)
34 Casting Input

Casting User Input

Wrap the input() function inside int() or float() to convert the text into a usable number.

input_cast.py
# Ask for age and immediately convert to integer
  age = int(input("Enter your age: "))

  # Now math works!
  future_age = age + 10
  print("In 10 years, you will be:", future_age)
34 Summary

Recap

✓Use input("Prompt: ") to pause and wait for the user.
✓The result of input() is ALWAYS a string.
✓Use int(input()) to get an integer from the user.
✓Use float(input()) to get a decimal from the user.
