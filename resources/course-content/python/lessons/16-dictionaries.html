Python Dictionaries

Dictionaries are used to store data values in key:value pairs.

16 Dictionaries

Creating Dictionaries

A dictionary is a collection which is ordered (as of Python 3.7), changeable and do not allow duplicates. They are written with curly brackets, and have keys and values.

dict.py
thisdict = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
  }
  print(thisdict)
16 Accessing

Accessing Items

You can access the items of a dictionary by referring to its key name, inside square brackets.

access.py
thisdict = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
  }

  x = thisdict["model"]
  print(x)

  # or use the get() method:
  y = thisdict.get("year")
  print(y)
16 Changing Values

Changing Values

You can change the value of a specific item by referring to its key name.

change.py
thisdict = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
  }

  thisdict["year"] = 2018
  print(thisdict)
16 Adding Items

Adding Items

Adding an item to the dictionary is done by using a new index key and assigning a value to it.

add.py
thisdict = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
  }

  thisdict["color"] = "red"
  print(thisdict)
16 Removing Items

Removing Items

There are several methods to remove items from a dictionary, but pop() is the most common.

remove.py
thisdict = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
  }

  thisdict.pop("model")
  print(thisdict)
16 Summary

Recap

✓Dictionaries are written with curly brackets, containing key-value pairs.
✓Access values using my_dict["key"].
✓Change values or add new items by assigning to a key: my_dict["new_key"] = 5.
✓Use pop("key") to remove an item.
