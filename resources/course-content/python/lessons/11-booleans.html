Python Booleans

Booleans represent one of two values: True or False.

11 True and False

Boolean Values

In programming you often need to know if an expression is True or False. These are called Boolean values.

bool.py
# Note the capital T and F!
  is_active = True
  is_admin = False

  print(is_active)
  print(type(is_active))  #
11 Comparisons

Boolean from Comparisons

When you compare two values, the expression is evaluated and Python returns a Boolean answer.

compare.py
print(10 > 9)    # True
  print(10 == 9)   # False
  print(10 < 9)    # False
11 If Statements

Booleans in if Statements

When you run a condition in an if statement, Python evaluates it and returns True or False to decide which block to execute.

if_bool.py
a = 200
  b = 33

  if b > a:
      print("b is greater than a")
  else:
      print("b is not greater than a")
11 bool() function

Evaluate Values

The bool() function allows you to evaluate any value, and give you True or False in return.

eval.py
# Almost everything has some sort of content and is True
  print(bool("Hello"))   # True
  print(bool(15))        # True
  print(bool([-1, 0]))   # True
11 Falsy Values

What Evaluates to False?

There are not many values that evaluate to False, except empty values, the number 0, and the value None.

falsy.py
print(bool(False))
  print(bool(None))
  print(bool(0))
  print(bool(""))      # empty string
  print(bool([]))      # empty list
  print(bool({}))      # empty dict
11 Summary

Recap

✓Booleans are either True or False (capitalized!).
✓Comparisons like 10 > 5 evaluate to a Boolean.
✓Almost all values are "truthy" (evaluate to True).
✓Empty strings, 0, None, and empty lists are "falsy" (evaluate to False).
