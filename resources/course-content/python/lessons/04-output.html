04 Python Programming Series

Python Output

Learn all the ways to display information to the screen using the print function.

04 print()

The print() Function

The print() function is used to output data to the standard output device (the screen).

print_basic.py
print("Welcome to Python!")
  print(100)
  print(3.14159)
04 Multiple Items

Printing Multiple Items

You can pass multiple items to the print() function, separated by commas. Python will automatically put a space between them.

multiple.py
name = "Alice"
  age = 25

  # Passing multiple arguments
  print("My name is", name, "and I am", age, "years old.")
04 sep Parameter

The 'sep' Parameter

By default, multiple items are separated by a space. You can change this using the sep parameter.

sep.py
# Separated by a dash
  print("Apple", "Banana", "Cherry", sep="-")

  # Separated by a newline
  print("One", "Two", "Three", sep="\n")
04 end Parameter

The 'end' Parameter

By default, print() adds a newline at the end. You can change this behavior using the end parameter to print on the same line.

end.py
print("Hello", end=" ")
  print("World!")

  # Ends with a smiley face
  print("Python is fun", end=" :)\n")
04 Summary

Recap

✓Use print() to show data on the screen.
✓Separate multiple items with commas.
✓Use sep="x" to change the separator between items.
✓Use end="x" to change what is printed at the very end.
