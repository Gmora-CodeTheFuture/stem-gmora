21 Functions

Creating a Function

In Python a function is defined using the def keyword.

func.py
def my_function():
      print("Hello from a function")

  # This won't output anything until we call it!
21 Calling Functions

Calling a Function

To call a function, use the function name followed by parenthesis.

call.py
def my_function():
      print("Hello from a function")

  my_function()
  my_function()
  my_function()
21 Arguments

Arguments (Inputs)

Information can be passed into functions as arguments. Arguments are specified after the function name, inside the parentheses.

args.py
def greet(fname):
      print(fname + " Johnson")

  greet("Emil")
  greet("Tobias")
  greet("Linus")
21 Multiple Arguments

Multiple Arguments

You can add as many arguments as you want, just separate them with a comma.

multi_args.py
def full_name(fname, lname):
      print(fname + " " + lname)

  full_name("Emil", "Refsnes")
21 Return Values

Returning Values

To let a function return a value back to the caller, use the return statement.

return.py
def my_function(x):
      return 5 * x

  print(my_function(3))
  print(my_function(5))
21 Summary

Recap

✓Use def func(): to define a new function.
✓Call it using its name and parentheses: func().
✓Add variables inside the parentheses to pass data (arguments).
✓Use return to send a computed value back out of the function.
