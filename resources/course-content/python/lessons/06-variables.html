06 Variables

What is a Variable?

Variables are containers for storing data values. Think of a variable as a labeled box where you can put information.

variables.py
# Creating variables
  x = 5
  y = "John"

  print(x)
  print(y)
06 No Command

No Declaration Command

Unlike other programming languages (like C++ or Java), Python has no command for declaring a variable. A variable is created the moment you first assign a value to it.

no_decl.py
# In Java you would write: int age = 25;
  # In Python, just write the name and the value:
  age = 25
  name = "Alice"

  print(name, "is", age)
06 Reassigning

Changing Variable Values

Variables do not need to be declared with any particular type, and can even change type after they have been set.

change.py
x = 4       # x is of type int
  print(x)

  x = "Sally" # x is now of type str
  print(x)
06 Naming Rules

Variable Names

A variable can have a short name (like x and y) or a more descriptive name (age, carname, total_volume). But there are rules.

rules.py
# Legal names
  myvar = "John"
  my_var = "John"
  _my_var = "John"

  # Illegal names (these will cause a SyntaxError)
  # 2myvar = "John"
  # my-var = "John"
  # my var = "John"

Variables must start with a letter or underscore, and can only contain alpha-numeric characters and underscores (A-z, 0-9, and _ ).

06 Multiple Variables

Many Values to Multiple Variables

Python allows you to assign values to multiple variables in one line.

multiple.py
x, y, z = "Orange", "Banana", "Cherry"
  print(x)
  print(y)
  print(z)
06 One Value

One Value to Multiple Variables

And you can assign the same value to multiple variables in one line.

one_val.py
x = y = z = "Orange"
  print(x)
  print(y)
  print(z)
06 Summary

Recap

✓Variables are created the moment you assign a value to them.
✓Variables can change their data type at any time.
✓Variable names cannot start with a number or contain spaces/dashes.
✓You can assign multiple variables in a single line.
