02 The Basics

What is Python?

Python is a general-purpose programming language — a way of giving a computer clear, step-by-step instructions, written in a form that reads almost like plain English.

✓Created by Guido van Rossum, first released in 1991.
✓Named after Monty Python's Flying Circus — not the snake.
✓Built around one core idea: code should be easy for humans to read.

05 Under the Hood

How your code actually runs

Python is an interpreted language — your code is read and run one line at a time, rather than compiled all at once.

You write code in a .py file
→
The Python interpreter reads it line by line
→
Your computer executes each instruction
06 Setup

Getting Python installed

Before writing any code, you need Python on your machine.

✓Download it from python.org/downloads — Windows, macOS, and Linux are all supported.
✓On Windows, tick “Add Python to PATH” during setup — this one checkbox saves a lot of headaches.
✓Confirm it worked by opening a terminal and running python --version
