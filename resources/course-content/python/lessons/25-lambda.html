Python Lambda

A lambda function is a small anonymous function. It can take any number of arguments, but can only have one expression.

25 Syntax

Lambda Syntax

The expression is executed and the result is returned automatically.

lambda.py
# lambda arguments : expression

  x = lambda a: a + 10
  print(x(5))
25 Multiple Arguments

Multiple Arguments

Lambda functions can take any number of arguments.

multi.py
# Multiply argument a with argument b and return the result
  x = lambda a, b: a * b
  print(x(5, 6))

  # Summarize argument a, b, and c and return the result
  y = lambda a, b, c: a + b + c
  print(y(5, 6, 2))
25 Why Use Lambda?

Why Use Lambda Functions?

The power of lambda is better shown when you use them as an anonymous function inside another function.

why.py
def myfunc(n):
      return lambda a: a * n

  # Make a function that always doubles the number you send in
  mydoubler = myfunc(2)

  print(mydoubler(11))
25 Use with Maps/Filters

Lambdas in Higher-Order Functions

They are often used with functions like filter() and map().

map_filter.py
nums = [1, 2, 3, 4, 5]

  # Map: double every number
  doubled = list(map(lambda x: x * 2, nums))
  print("Doubled:", doubled)

  # Filter: keep only even numbers
  evens = list(filter(lambda x: x % 2 == 0, nums))
  print("Evens:", evens)
25 Summary

Recap

✓Lambdas are written as: lambda args: expression.
✓They are limited to a single expression (no multi-line blocks).
✓They automatically return the result of the expression.
✓Best used when passing a simple function into another function like map().
