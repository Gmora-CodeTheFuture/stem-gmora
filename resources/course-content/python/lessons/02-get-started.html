02 Python Programming Series

Get Started

Setting up your environment and running your very first script on your own machine.

02 Installation

Installing Python

Before you can write Python code, you need to install the Python interpreter on your computer.

✓Go to python.org/downloads
✓Download the latest version for your OS (Windows/Mac/Linux).
✓Important: On Windows, make sure to check "Add Python to PATH" during installation.
02 Verification

Checking Your Installation

Open your terminal or command prompt and type the following command to check if Python is installed correctly.

Terminal
python --version
  # or on some Macs/Linux:
  python3 --version
02 Code Editors

Choosing an IDE

An IDE (Integrated Development Environment) is software for writing your code. You can use simple text editors, but IDEs have features like syntax highlighting and autocompletion.

VS Code

Visual Studio Code

Free, lightweight, and very popular. Recommended for beginners.

PyCharm

JetBrains PyCharm

A powerful IDE designed specifically for Python. Has a free community edition.

02 First Program

Your First Program

In Python, we can display text to the screen using the print() function.

hello.py
print("Hello, World!")
  print("I am learning Python!")
02 Running Code

Running Python Scripts

Once you save your code in a file ending in .py, you can run it from the terminal.

Terminal
# Navigate to your folder
  cd path/to/folder

  # Run the script
  python hello.py
02 REPL

Interactive Python (REPL)

If you type python in the terminal without a filename, it opens the REPL (Read-Eval-Print Loop). It's great for quick tests.

Terminal
>>> print("Hello from REPL")
  Hello from REPL
  >>> 5 + 7
  12
  >>> exit()  # To leave the REPL
02 Summary

Recap

✓Install Python from python.org.
✓Choose a code editor like VS Code or PyCharm.
✓Python files must end with the .py extension.
✓Run files from the terminal using python filename.py.
