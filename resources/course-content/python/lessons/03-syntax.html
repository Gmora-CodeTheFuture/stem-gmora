Python Syntax

The rules of the language. How Python uses whitespace and indentation to understand your code.

03 Indentation

Whitespace Matters

Unlike other languages that use curly brackets {}, Python uses indentation (spaces) to define blocks of code.

syntax.py
if 5 > 2:
      # This is indented, so it belongs to the if statement
      print("Five is greater than two!")
03 Errors

IndentationError

If you skip the indentation, Python will throw an error and refuse to run.

error.py
if 5 > 2:
  print("Five is greater than two!") # Error! Missing indentation
03 Summary

Recap

✓Python uses new lines to complete a command.
✓Indentation defines scope (loops, functions, classes).
✓You must be consistent with the number of spaces you use.
