41 Read Lines

Read Lines

You can return one line by using the readline() method. By calling readline() two times, you can read the two first lines.

lines.py
# Example code
  # f = open("demofile.txt", "r")
  # print(f.readline())
  # print(f.readline())
  # f.close()
  print("Use readline() for one line at a time.")
41 Loop Through Lines

Looping Lines

By looping through the lines of the file, you can read the whole file, line by line. This is the most efficient way to read large files.

loop_lines.py
# Example code
  # f = open("demofile.txt", "r")
  # for x in f:
  #   print(x)
  # f.close()
  print("For loop reads lines efficiently.")
