Python Modules

Consider a module to be the same as a code library, a file containing a set of functions you want to include in your application.

29 What is a Module?

What is a Module?

To create a module just save the code you want in a file with the file extension .py.

mymodule.py
# Save this in mymodule.py
  def greeting(name):
      print("Hello, " + name)
    
  person1 = {
    "name": "John",
    "age": 36,
    "country": "Norway"
  }
29 Importing Modules

Using a Module

Now we can use the module we just created, by using the import statement.

main.py
import math

  # Here we import a built-in module 'math'
  # But you would import 'mymodule' the exact same way!

  print(math.pi)
29 Renaming Modules

Re-naming a Module

You can create an alias when you import a module, by using the as keyword.

alias.py
import math as m

  print(m.pi)
  print(m.sqrt(16))
29 Built-in Modules

Built-in Modules

There are several built-in modules in Python, which you can import whenever you like. Like the platform module.

platform_mod.py
import platform

  x = platform.system()
  print("You are running on:", x)
29 From... Import

Import From Module

You can choose to import only parts from a module, by using the from keyword.

from.py
# Import just the pi variable from math
  from math import pi

  print(pi)
  # Notice we don't need to write math.pi anymore!
29 Summary

Recap

✓Use import module_name to bring in external code.
✓Use import module as alias to rename it for convenience.
✓Use from module import specific_part to import just one piece.
✓Any Python file you create can be imported as a module!
