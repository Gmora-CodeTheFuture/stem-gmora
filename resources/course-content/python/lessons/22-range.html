The range() Function

How to easily generate sequences of numbers in Python.

22 Range Intro

What is range()?

The range() function returns a sequence of numbers, starting from 0 by default, and increments by 1 (by default), and stops before a specified number.

range_basic.py
# Range generates numbers from 0 up to (but not including) 5
  for x in range(5):
      print(x)
22 Start Parameter

Custom Start Value

You can provide two numbers to range: range(start, stop).

range_start.py
# Start at 2, go up to (but not including) 6
  for x in range(2, 6):
      print(x)
22 Step Parameter

Custom Step (Increment)

You can provide a third number to range to define the increment (step): range(start, stop, step).

range_step.py
# Start at 2, up to 30, increasing by 3
  for x in range(2, 15, 3):
      print(x)
22 Negative Step

Counting Backwards

You can use a negative step to count backwards!

range_negative.py
# Start at 5, go down to (but not including) 0, stepping by -1
  for x in range(5, 0, -1):
      print(x)
  print("Blast off!")
22 Range to List

Converting Range to a List

The range() function doesn't actually create all the numbers in memory at once (for efficiency). If you need an actual list, cast it!

range_list.py
r = range(5)
  print(r)           # Prints: range(0, 5)

  my_list = list(r)  # Convert to a real list
  print(my_list)     # Prints: [0, 1, 2, 3, 4]
22 Summary

Recap

✓range(5) generates 0, 1, 2, 3, 4.
✓range(start, stop) lets you set a custom start value.
✓range(start, stop, step) lets you skip numbers or count backwards.
✓The stop number is never included in the output.
