Python Scope

A variable is only available from inside the region it is created. This is called scope.

30 Local Scope

Local Scope

A variable created inside a function belongs to the local scope of that function, and can only be used inside that function.

local.py
def myfunc():
      x = 300
      print("Inside function:", x)

  myfunc()
  # print(x)  # This will cause an error because x is local!
30 Global Scope

Global Scope

A variable created in the main body of the Python code is a global variable and belongs to the global scope. Global variables are available from within any scope, global and local.

global.py
x = 300

  def myfunc():
      # We can read the global x inside the function
      print("Inside function:", x)

  myfunc()
  print("Outside function:", x)
30 Naming Conflicts

Naming Variables

If you operate with the same variable name inside and outside of a function, Python will treat them as two separate variables.

conflict.py
x = 300

  def myfunc():
      # This x is local! It doesn't change the global x
      x = 200
      print("Local x:", x)

  myfunc()
  print("Global x:", x)
30 The Global Keyword

The global Keyword

If you need to create or change a global variable from inside a function, you can use the global keyword.

keyword.py
x = 300

  def myfunc():
      global x
      # This now modifies the global x!
      x = 200

  myfunc()
  print(x)
30 Summary

Recap

✓Local scope: Variables created inside a function.
✓Global scope: Variables created at the top level of the script.
✓Local variables take precedence over global variables with the same name.
✓Use the global keyword to modify global variables from within a function.
