The None Keyword

Understanding Python's way of representing "nothing" or "no value".

33 What is None?

What is None?

The None keyword is used to define a null variable or an object. In Python, None is its own unique data type (NoneType).

none_basic.py
x = None
  print(x)
  print(type(x))
33 None is not Zero

None vs Empty/Zero

None is not the same as 0, False, or an empty string. None is literally nothing.

none_vs_zero.py
x = None

  print(x == 0)       # False
  print(x == "")      # False
  print(x == False)   # False
  print(x == None)    # True
33 is Keyword

Checking for None

Because None is a unique singleton object in Python, the best way to check if a variable is None is by using the is operator.

is_none.py
x = None

  if x is None:
      print("Yes, x is None")
  else:
      print("No, x has a value")
33 Functions

None from Functions

If a function doesn't explicitly return a value, it automatically returns None.

func_none.py
def my_function():
      print("I am doing work, but returning nothing.")
      # Notice there is no 'return' statement here

  result = my_function()
  print("The result is:", result)
33 Summary

Recap

✓None represents the absence of a value (null).
✓None is NOT the same as 0 or "" or False.
✓Use x is None to check for it, rather than ==.
✓Functions return None if no return statement is provided.
