Python PIP

PIP is a package manager for Python packages, or modules if you like.

38 Packages

What is a Package?

A package contains all the files you need for a module. Modules are Python code libraries you can include in your project. PIP allows you to install them easily.

Terminal
# Check if you have pip installed:
  pip --version

  # If not installed, you can get it from pypi.org
38 Install

Installing a Package

Navigate your command line to the location of Python's script directory, and type the following:

Terminal
# Download a package named camelcase:
  pip install camelcase

  # Now you can use it in your code!
38 Using Packages

38 Uninstalling

Uninstall and List

Use the uninstall command to remove a package, and the list command to see what you have installed.

Terminal
# Remove the camelcase package
  pip uninstall camelcase

  # List all installed packages
  pip list
38 Summary
