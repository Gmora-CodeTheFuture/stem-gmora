File Handling

File handling is an important part of any web application. Python has several functions for creating, reading, updating, and deleting files.

40 Open Function

File Handling

The key function for working with files in Python is the open() function. It takes two parameters: filename, and mode.

"r"

Read

Default value. Opens a file for reading, error if the file does not exist.

"a"

Append

Opens a file for appending, creates the file if it does not exist.

"w"

Write

Opens a file for writing, creates the file if it does not exist.

"x"

Create

Creates the specified file, returns an error if the file exists.

40 Syntax

Syntax

To open a file for reading it is enough to specify the name of the file, because "r" for read is the default mode.

open.py
# This assumes demofile.txt exists in the same folder
  # f = open("demofile.txt")

  # f = open("demofile.txt", "rt")

40 Text vs Binary

Text vs Binary

In addition to the mode (r, w, a, x), you can specify if the file should be handled as binary or text mode.

  • "t" - Text - Default value. Text mode.
  • "b" - Binary - Binary mode (e.g. images).
