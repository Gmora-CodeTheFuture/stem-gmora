Python Sets

Sets are used to store multiple items, but they are unordered and do not allow duplicate values.

15 Sets

Creating Sets

Sets are written with curly brackets {}. They are unordered, unchangeable*, and unindexed.

sets.py
thisset = {"apple", "banana", "cherry"}
  print(thisset)
  # Note: the items will appear in a random order!
15 Duplicates

No Duplicates Allowed

Sets cannot have two items with the same value. Duplicate values will be ignored.

dupes.py
thisset = {"apple", "banana", "apple"}

  print(thisset)
  # "apple" will only appear once
15 Access Items

Accessing Items

You cannot access items in a set by referring to an index or a key. You must use a for loop.

access.py
thisset = {"apple", "banana", "cherry"}

  for x in thisset:
      print(x)

  # Check if "banana" is in the set
  print("banana" in thisset)
15 Add Items

Adding Items

Once a set is created, you cannot change its items, but you can add new items using the add() method.

add.py
thisset = {"apple", "banana", "cherry"}

  thisset.add("orange")
  print(thisset)
15 Remove Items

Removing Items

To remove an item in a set, use the remove(), or the discard() method.

remove.py
thisset = {"apple", "banana", "cherry"}

  thisset.remove("banana")
  print(thisset)

  thisset.discard("apple")
  print(thisset)
15 Summary

Recap

✓Sets are written with curly brackets {}.
✓They are unordered (no index numbers) and do not allow duplicates.
✓Use add() to insert an item into a set.
✓Use remove() or discard() to take an item out.
