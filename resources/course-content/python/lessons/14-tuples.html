Python Tuples

Tuples are used to store multiple items, but unlike lists, they cannot be changed.

14 Tuples

Creating Tuples

Tuples are written with round brackets (). They are ordered and unchangeable (immutable).

tuples.py
thistuple = ("apple", "banana", "cherry")
  print(thistuple)

  # Tuples allow duplicate values
  dupes = ("apple", "apple", "apple")
  print(dupes)
14 Access Items

Accessing Items

You can access tuple items by referring to the index number, inside square brackets, exactly like lists.

access.py
thistuple = ("apple", "banana", "cherry")
  print(thistuple[1])

  # Negative indexing
  print(thistuple[-1])
14 Unchangeable

Tuples are Unchangeable

Once a tuple is created, you cannot change its values. Tuples are unchangeable, or immutable as it also is called.

immutable.py
x = ("apple", "banana", "cherry")

  # This will cause an error (TypeError)
  # x[1] = "kiwi"

  print(x)
14 Workaround

Changing a Tuple (Workaround)

To change a tuple, you can convert it into a list, change the list, and convert the list back into a tuple.

workaround.py
x = ("apple", "banana", "cherry")
  y = list(x)
  y[1] = "kiwi"
  x = tuple(y)

  print(x)
14 One Item Tuple

Create Tuple With One Item

To create a tuple with only one item, you have to add a comma after the item, otherwise Python will not recognize it as a tuple.

one_item.py
thistuple = ("apple",)
  print(type(thistuple))

  # NOT a tuple
  not_a_tuple = ("apple")
  print(type(not_a_tuple))  # This is a string!
14 Summary

Recap

✓Tuples are written with round brackets ().
✓They are ordered but CANNOT be changed (immutable).
✓You can access items using index numbers, just like lists.
✓A one-item tuple must have a trailing comma: ("apple",).
