10 Strings

What are Strings?

Strings in python are surrounded by either single quotation marks, or double quotation marks.

strings.py
print("Hello")
  print('Hello')

  # Both are identical in Python
  a = "Hello"
  b = 'Hello'
  print(a == b)  # Returns True
10 Quotes Inside Quotes

Quotes Inside Quotes

You can use quotes inside a string, as long as they don't match the quotes surrounding the string.

quotes.py
print("It's alright")
  print("He is called 'Johnny'")
  print('He is called "Johnny"')
10 Arrays

Strings are Arrays

Like many other languages, strings in Python are arrays of bytes representing unicode characters. You can access elements using square brackets.

array.py
a = "Hello, World!"

  # Get the character at position 1 (remember that the first character has the position 0)
  print(a[1])

  # Get the first character
  print(a[0])
10 Length

String Length

To get the length of a string, use the len() function.

len.py
a = "Hello, World!"
  print(len(a))  # Returns 13 (including space and punctuation)
10 Slicing

Slicing Strings

You can return a range of characters by using the slice syntax. Specify the start index and the end index, separated by a colon.

slice.py
b = "Hello, World!"

  # Get characters from position 2 to position 5 (not included)
  print(b[2:5])

  # Get characters from the start to position 5 (not included)
  print(b[:5])

  # Get characters from position 7 to the end
  print(b[7:])
10 Methods

String Methods

Python has a set of built-in methods that you can use on strings.

methods.py
a = " Hello, World! "

  print(a.upper())      # " HELLO, WORLD! "
  print(a.lower())      # " hello, world! "
  print(a.strip())      # "Hello, World!" (removes whitespace)
  print(a.replace("H", "J")) # " Jello, World! "
10 F-Strings

F-Strings (Formatting)

To combine strings and numbers, we use f-strings. Put an f in front of the string, and use curly brackets {} for variables.

fstrings.py
age = 36
  name = "John"

  # Use f before the quote
  txt = f"My name is {name}, and I am {age}"
  print(txt)

  # You can even do math inside!
  print(f"Next year I will be {age + 1}")
10 Summary

Recap

✓Strings are arrays of characters, index starts at 0.
✓Use [start:end] to slice strings.
✓Use methods like upper(), lower(), and replace() to modify.
✓Use f-strings f"Text {var}" to easily format strings and numbers.
