Python If...Else

How to run different code depending on whether a condition is true or false.

17 If Statement

The if Statement

An if statement is written by using the if keyword. The code block inside the if statement is only executed if the condition is True.

if_stmt.py
a = 33
  b = 200

  if b > a:
      print("b is greater than a")
17 Indentation

Indentation is Crucial

Python relies on indentation (whitespace at the beginning of a line) to define scope in the code. Other languages often use curly brackets.

indent.py
a = 33
  b = 200

  # This will work:
  if b > a:
      print("b is greater than a")
    
  # This will throw an IndentationError:
  # if b > a:
  # print("b is greater than a")
17 Elif

The elif Keyword

The elif keyword is Python's way of saying "if the previous conditions were not true, then try this condition".

elif.py
a = 33
  b = 33

  if b > a:
      print("b is greater than a")
  elif a == b:
      print("a and b are equal")
17 Else

The else Keyword

The else keyword catches anything which isn't caught by the preceding conditions.

else.py
a = 200
  b = 33

  if b > a:
      print("b is greater than a")
  elif a == b:
      print("a and b are equal")
  else:
      print("a is greater than b")
17 And / Or

Logical Conditions

You can combine multiple conditions using and, or, and not.

logic.py
a = 200
  b = 33
  c = 500

  if a > b and c > a:
      print("Both conditions are True")
    
  if a > b or a > c:
      print("At least one of the conditions is True")
17 Summary

Recap

✓Use if condition: followed by indented code block.
✓Use elif condition: for additional conditions.
✓Use else: for the fallback block.
✓Indentation (spaces) is strictly required by Python to denote blocks.
