Python JSON

JSON is a syntax for storing and exchanging data. Python has a built-in package called json to work with JSON data.

36 Parse JSON

JSON to Python

If you have a JSON string, you can parse it by using the json.loads() method. The result will be a Python dictionary.

parse.py
import json

  # some JSON string:
  x =  '{ "name":"John", "age":30, "city":"New York"}'

  # parse x:
  y = json.loads(x)

  # the result is a Python dictionary:
  print(y["age"])
36 Convert to JSON

Python to JSON

If you have a Python object, you can convert it into a JSON string by using the json.dumps() method.

convert.py
import json

  # a Python object (dict):
  x = {
    "name": "John",
    "age": 30,
    "city": "New York"
  }

  # convert into JSON:
  y = json.dumps(x)

  # the result is a JSON string:
  print(y)
36 Formatting

Format the Result

The json.dumps() method has parameters to make it easier to read the result.

format.py
import json

  x = {"name": "John", "age": 30, "city": "New York"}

  # use four indents to make it easier to read
  print(json.dumps(x, indent=4))
36 Summary

Recap

✓Use json.dumps() to convert a Python Dictionary into a JSON string.
