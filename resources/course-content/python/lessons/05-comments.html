Python Comments

How to write notes for humans inside your Python code.

05 Comments

What are Comments?

Comments are text inside your code that Python ignores. They are used to explain what the code does or to temporarily disable code.

comments.py
# This is a comment. Python ignores this line.
  print("Hello, World!")

  # print("This will not print")
05 Single Line

Single Line Comments

A single-line comment starts with the hash symbol (#). Anything after the hash on that line is ignored.

single.py
# We can place comments on their own line
  x = 5

  print(x)  # Or we can place them at the end of a line of code
05 Multi Line

Multi Line Comments

Python does not have a specific syntax for multi-line comments. You can simply use a # on each line.

multi.py
# This is a comment
  # written in
  # more than just one line
  print("Multi-line comments!")
05 Docstrings

String Literals as Comments

Since Python ignores string literals that are not assigned to a variable, you can use multi-line strings (""") as comments.

docstring.py
"""
  This is a multi-line string.
  Since it is not assigned to a variable,
  Python reads it but ignores it.
  Many developers use this for multi-line comments.
  """
  print("It works!")
05 Summary

Recap

✓Use # for single-line comments.
✓Comments can go on a new line or at the end of a line.
✓Use """ (triple quotes) for large, multi-line comment blocks.
✓Use comments to explain complex logic or disable code for testing.
