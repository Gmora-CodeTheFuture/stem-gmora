42 Append vs Write

Write to an Existing File

To write to an existing file, you must add a parameter to the open() function: "a" (Append) or "w" (Write - overwrites content).

write.py
# Example of Appending
  # f = open("demofile2.txt", "a")
  # f.write("Now the file has more content!")
  # f.close()

  # Example of Overwriting
  # f = open("demofile3.txt", "w")
  # f.write("Woops! I have deleted the content!")
  # f.close()
  print("Remember to always close() files!")
