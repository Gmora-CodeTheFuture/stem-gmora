07 Data Types

Built-in Data Types

Variables can store data of different types, and different types can do different things.

Text

str

Strings are used to store text. e.g. "Hello"

Numeric

int, float, complex

Used to store numbers. e.g. 10 or 3.14

Sequence

list, tuple, range

Used to store a collection of items.

Mapping

dict

Used to store key-value pairs (like a dictionary).

07 type()

Getting the Data Type

You can get the data type of any object by using the type() function.

types.py
x = 5
  print(type(x))

  y = "Hello World"
  print(type(y))

  z = 3.14
  print(type(z))
07 Setting Types

Setting the Data Type

In Python, the data type is set automatically when you assign a value to a variable.

set_types.py
x = "Hello World"    # str
  x = 20               # int
  x = 20.5             # float
  x = ["apple", "banana"]  # list
  x = ("apple", "banana")  # tuple
  x = {"name": "John"} # dict
  x = True             # bool
  print("Done!")
07 Explicit Types

Setting Specific Data Type

If you want to specify the data type, you can use the constructor functions (casting).

explicit.py
x = str("Hello World")
  y = int(20)
  z = float(20.5)
  w = list(("apple", "banana"))

  print(x, y, z, w)
