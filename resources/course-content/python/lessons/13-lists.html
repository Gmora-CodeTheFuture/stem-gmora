Python Lists

Lists are used to store multiple items in a single variable.

13 Lists

Creating Lists

Lists are created using square brackets []. They are ordered and changeable (mutable).

lists.py
thislist = ["apple", "banana", "cherry"]
  print(thislist)

  # Lists allow duplicate values
  dupes = ["apple", "apple", "apple"]
  print(dupes)
13 Access Items

Accessing Items

List items are indexed, the first item has index [0], the second item has index [1] etc.

access.py
thislist = ["apple", "banana", "cherry"]
  print(thislist[1])  # Prints "banana"

  # Negative indexing means start from the end
  print(thislist[-1]) # Prints "cherry"
13 Change Items

Changing Items

To change the value of a specific item, refer to the index number.

change.py
thislist = ["apple", "banana", "cherry"]

  thislist[1] = "blackcurrant"
  print(thislist)
13 Add Items

Adding Items

To add an item to the end of the list, use the append() method. To insert at a specific index, use insert().

add.py
thislist = ["apple", "banana"]

  thislist.append("orange")
  print(thislist)

  thislist.insert(1, "lemon")
  print(thislist)
13 Remove Items

Removing Items

You can remove items by value using remove(), or by index using pop().

remove.py
thislist = ["apple", "banana", "cherry"]

  thislist.remove("banana")
  print(thislist)

  # pop() removes the last item if no index is specified
  thislist.pop()
  print(thislist)
13 Summary

Recap

✓Lists are written with square brackets [].
✓They are ordered and can be changed (mutable).
✓Use append() to add to the end, insert() to add anywhere.
✓Use remove() or pop() to remove items.
