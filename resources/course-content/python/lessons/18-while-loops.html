18 While Loops

The while Loop

With the while loop we can execute a set of statements as long as a condition is true.

while.py
i = 1
  while i < 6:
      print(i)
      i += 1

Warning: Remember to increment i, or else the loop will continue forever!

18 Break Statement

The break Statement

With the break statement we can stop the loop even if the while condition is true.

break.py
i = 1
  while i < 6:
      print(i)
      if i == 3:
          break
      i += 1
  print("Loop ended!")
18 Continue Statement

The continue Statement

With the continue statement we can stop the current iteration, and continue with the next.

continue.py
i = 0
  while i < 6:
      i += 1
      if i == 3:
          continue
      print(i)
  # Notice that the number 3 is missing!
18 Else in While

The else Statement

With the else statement we can run a block of code once when the condition no longer is true.

else.py
i = 1
  while i < 6:
      print(i)
      i += 1
  else:
      print("i is no longer less than 6")
18 Summary

Recap

✓while condition: loops as long as the condition is true.
✓Always ensure your condition will eventually become false.
✓Use break to exit the loop entirely.
✓Use continue to skip to the next iteration.
