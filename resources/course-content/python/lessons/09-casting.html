Type Casting

How to convert data from one type (like a string) to another type (like an integer).

09 What is Casting?

What is Casting?

There may be times when you want to specify a type on to a variable. This is done with casting functions.

int()

Integer Casting

Converts a float or a string into an integer (whole number).

str()

String Casting

Converts a number into text.

09 Integer Casting

Casting to Integers

Use int() to construct an integer number from a float or a string (providing the string represents a whole number).

cast_int.py
x = int(1)       # x will be 1
  y = int(2.8)     # y will be 2 (decimals are removed)
  z = int("3")     # z will be 3

  print(x, y, z)
  print(type(z))   # It's an int!
09 Float Casting

Casting to Floats

Use float() to construct a float number from an integer, another float, or a string.

cast_float.py
x = float(1)       # x will be 1.0
  y = float(2.8)     # y will be 2.8
  z = float("3")     # z will be 3.0
  w = float("4.2")   # w will be 4.2

  print(x, y, z, w)
09 String Casting

Casting to Strings

Use str() to construct a string from a wide variety of data types, including numbers.

cast_str.py
x = str("s1")    # x will be 's1'
  y = str(2)       # y will be '2'
  z = str(3.0)     # z will be '3.0'

  # Now we can concatenate it with other strings
  print("I have " + y + " apples.")
09 Errors in Casting

Casting Errors

You can only cast compatible types. Trying to cast letters to an integer will crash your program.

cast_error.py
# This works perfectly
  num = int("150")
  print(num)

  # This will throw a ValueError
  bad_num = int("hello")
09 Summary

Recap

✓Use int() to turn numbers/strings into whole numbers.
✓Use float() to turn numbers/strings into decimal numbers.
✓Use str() to turn any data into text.
✓int(3.9) becomes 3 (it truncates, it does not round up).
