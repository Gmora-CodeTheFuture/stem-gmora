Python Arrays

Note: Python does not have built-in support for Arrays, but Python Lists can be used instead.

23 Arrays vs Lists

Lists as Arrays

Arrays are used to store multiple values in one single variable. In Python, we simply use lists to act as arrays.

arrays.py
cars = ["Ford", "Volvo", "BMW"]

  print(cars)
  print(type(cars))  # Prints
23 Accessing Elements

Access the Elements of an Array

You refer to an array element by referring to the index number.

access.py
cars = ["Ford", "Volvo", "BMW"]

  # Get the first item
  x = cars[0]
  print(x)

  # Modify the first item
  cars[0] = "Toyota"
  print(cars)
23 Length

The Length of an Array

Use the len() method to return the length of an array (the number of elements in an array).

length.py
cars = ["Ford", "Volvo", "BMW"]

  x = len(cars)
  print("There are", x, "cars in the array.")
23 Iterating

Looping Array Elements

You can use the for in loop to loop through all the elements of an array.

loop.py
cars = ["Ford", "Volvo", "BMW"]

  for x in cars:
      print(x)
23 Methods

Adding and Removing

You can use the append() method to add an element, and pop() or remove() to remove elements.

methods.py
cars = ["Ford", "Volvo", "BMW"]

  cars.append("Honda")
  print(cars)

  cars.pop(1)  # removes Volvo
  print(cars)

  cars.remove("BMW")
  print(cars)
23 Summary

Recap

✓Python doesn't have a native "array" type; we use Lists.
✓Lists can do everything arrays can do, and more.
✓If you need strictly typed arrays for performance (math/science), you import numpy.
