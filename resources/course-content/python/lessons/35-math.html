Python Math

Python has a set of built-in math functions, including an extensive math module, that allows you to perform mathematical tasks on numbers.

35 Min and Max

Built-in Math Functions

The min() and max() functions can be used to find the lowest or highest value in an iterable.

minmax.py
x = min(5, 10, 25)
  y = max(5, 10, 25)

  print("Minimum is:", x)
  print("Maximum is:", y)
35 Abs and Pow

Abs and Pow

The abs() function returns the absolute (positive) value. The pow() function returns the value of x to the power of y.

abspow.py
x = abs(-7.25)
  print(x)

  # Return the value of 4 to the power of 3 (same as 4 * 4 * 4)
  y = pow(4, 3)
  print(y)
35 The Math Module

The Math Module

Python has also a built-in module called math, which extends the list of mathematical functions.

mathmod.py
import math

  # Square root
  x = math.sqrt(64)
  print(x)
35 Ceil and Floor

Rounding Up and Down

The math.ceil() method rounds a number upwards to its nearest integer, and math.floor() rounds down.

round.py
import math

  x = math.ceil(1.4)
  y = math.floor(1.4)

  print(x) # Returns 2
  print(y) # Returns 1
35 Constants

Math Constants

The math module also contains useful mathematical constants, such as Pi.

const.py
import math

  # Print the value of pi
  print(math.pi)

  # Print Euler's number
  print(math.e)
