Structural Pattern Matching

How to use the match-case statement (introduced in Python 3.10) for cleaner conditional logic.

20 What is Match Case?

Match Case Statement

Similar to the switch statement in C, Java or JavaScript, the match statement takes an expression and compares its value to successive patterns given as one or more case blocks.

match.py
status = 404

  match status:
      case 200:
          print("OK")
      case 400:
          print("Bad Request")
      case 404:
          print("Not Found")
20 The Default Case

The Default Case (_)

If an exact match is not confirmed, the last case, a wildcard _, is used as the matching case. Think of this as the "else" branch.

default.py
status = 418

  match status:
      case 200:
          print("OK")
      case 404:
          print("Not Found")
      case _:
          print("Something's wrong with the internet")
20 Combining Patterns

Combining Patterns

You can combine several literals in a single pattern using | ("or").

combine.py
status = 403

  match status:
      case 401 | 403:
          print("Authentication Error")
      case 200:
          print("OK")
      case _:
          print("Other")
20 Advanced Matching

Matching Lists & Tuples

Match-case is extremely powerful because it can unpack values and match shapes of data.

unpack.py
point = (0, 5)

  match point:
      case (0, 0):
          print("Origin")
      case (0, y):
          print(f"Y-axis, value is {y}")
      case (x, 0):
          print(f"X-axis, value is {x}")
      case (x, y):
          print(f"Point is at {x}, {y}")
20 Summary

Recap

✓match variable: initiates the match block.
✓case pattern: acts like an elif checking for equality.
✓case _: acts like an else statement for unmatched cases.
✓Use | to combine multiple matches into one case.
