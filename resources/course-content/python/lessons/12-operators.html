12 Operators

What are Operators?

Operators are special symbols in Python that carry out arithmetic or logical computation.

+ - * /

Arithmetic

Used for math operations.

= += -=

Assignment

Used to assign values to variables.

== > <

Comparison

Used to compare two values.

and or not

Logical

Used to combine conditional statements.

12 Arithmetic

Arithmetic Operators

Arithmetic operators are used with numeric values to perform common mathematical operations.

math.py
print(10 + 3)  # Addition: 13
  print(10 - 3)  # Subtraction: 7
  print(10 * 3)  # Multiplication: 30
  print(10 / 3)  # Division: 3.3333333333333335
12 Advanced Arithmetic

Advanced Arithmetic

Python also has built-in operators for floor division, modulus (remainder), and exponentiation.

adv_math.py
print(10 // 3) # Floor division (rounds down): 3
  print(10 % 3)  # Modulus (remainder): 1
  print(10 ** 3) # Exponentiation (10 to power of 3): 1000
12 Assignment

Assignment Operators

Assignment operators are used to assign values to variables. You can combine math and assignment in one step.

assign.py
x = 5
  print(x)

  x += 3   # Same as: x = x + 3
  print(x)

  x *= 2   # Same as: x = x * 2
  print(x)
12 Comparison

Comparison Operators

Comparison operators are used to compare two values. They always return a Boolean (True or False).

compare.py
x = 5
  y = 3

  print(x == y)  # Equal
  print(x != y)  # Not equal
  print(x > y)   # Greater than
  print(x <= y)  # Less than or equal to
12 Logical

Logical Operators

Logical operators are used to combine conditional statements.

logical.py
x = 5

  # and: Returns True if both statements are true
  print(x > 3 and x < 10)

  # or: Returns True if one of the statements is true
  print(x > 10 or x < 6)

  # not: Reverse the result
  print(not(x > 3 and x < 10))
12 Summary

Recap

✓Math operators include +, -, *, /, //, %, **.
✓Use += to add a number to an existing variable.
✓Comparison operators like == and != return Booleans.
✓Logical operators are written as words: and, or, not.
