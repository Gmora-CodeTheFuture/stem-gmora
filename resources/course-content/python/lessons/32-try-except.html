Python Try Except

The try block lets you test a block of code for errors. The except block lets you handle the error.

32 Exception Handling

Exception Handling

When an error occurs, or exception as we call it, Python will normally stop and generate an error message. These exceptions can be handled using the try statement.

try.py
try:
      print(variable_that_does_not_exist)
  except:
      print("An exception occurred!")
    
  # Without the try block, the program would crash here
32 Many Exceptions

Many Exceptions

You can define as many exception blocks as you want, e.g. if you want to execute a special block of code for a special kind of error.

many.py
try:
      print(x)
  except NameError:
      print("Variable x is not defined")
  except:
      print("Something else went wrong")
32 Else

Else Statement

You can use the else keyword to define a block of code to be executed if no errors were raised.

else.py
try:
      print("Hello")
  except:
      print("Something went wrong")
  else:
      print("Nothing went wrong")
32 Finally

Finally Statement

The finally block, if specified, will be executed regardless if the try block raises an error or not. Useful for closing files/connections.

finally.py
try:
      print(x)
  except:
      print("Something went wrong")
  finally:
      print("The 'try except' is finished")
32 Raise

Raise an exception

As a Python developer you can choose to throw an exception if a condition occurs. To throw (or raise) an exception, use the raise keyword.

raise.py
x = -1

  if x < 0:
      raise Exception("Sorry, no numbers below zero")
32 Summary

Recap

✓Use try: to test a block of code for errors.
✓Use except: to handle the error without crashing the program.
✓Use finally: to run cleanup code regardless of success or failure.
✓Use raise Exception("msg") to trigger your own errors.
