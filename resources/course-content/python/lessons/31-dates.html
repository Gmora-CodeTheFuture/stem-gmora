Python Dates

A date in Python is not a data type of its own, but we can import a module named datetime to work with dates as date objects.

31 Datetime Module

Python Datetime

Import the datetime module and display the current date.

date.py
import datetime

  x = datetime.datetime.now()
  print(x)
  # Output will look something like: 2026-08-25 15:30:00.123456
31 Date Output

Date Output Analysis

The date contains year, month, day, hour, minute, second, and microsecond. The datetime module has many methods to return information about the date object.

date_parts.py
import datetime

  x = datetime.datetime.now()

  print(x.year)
  print(x.strftime("%A")) # Returns the weekday
31 Creating Dates

Creating Date Objects

To create a date, we can use the datetime() class (constructor) of the datetime module. It requires three parameters to create a date: year, month, day.

create.py
import datetime

  # Year, Month, Day
  x = datetime.datetime(2020, 5, 17)

  print(x)
31 strftime Method

The strftime() Method

The datetime object has a method for formatting date objects into readable strings. The method is called strftime(), and takes one parameter, format, to specify the format of the returned string.

format.py
import datetime

  x = datetime.datetime(2018, 6, 1)

  # %B prints the full month name
  print(x.strftime("%B"))
31 Summary

Recap

✓Use import datetime to work with dates.
✓Use datetime.datetime.now() for the current time.
✓Use datetime.datetime(year, month, day) to create specific dates.
✓Use strftime("%format") to format a date into a custom string.
